## Descripción del Proyecto
GameVault es una aplicación móvil desarrollada en React Native que permite a los usuarios explorar videojuegos, consultar noticias del mundo gaming y mantener listas de juegos deseados. La app incluye formularios para agregar nuevos juegos y simulaciones de carga para mejorar la experiencia de usuario.
